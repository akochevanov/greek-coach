# Родительный падеж (γενική)

Родительный отвечает на вопросы **кого? чего? чей?**  
Чаще всего: принадлежность (*книга Анны*), часть от целого, после некоторых предлогов и глаголов.

В современном греческом родительный часто заменяют конструкцией с **από** + винительный  
(*το βιβλίο από την Άννα*), но классическая форма с артиклем **του / της / των** всё ещё нужна.

---

## Артикль в родительном

### Определённый (ο / η / το)

«Этот / тот самый»: *книга Анны*, *дом друга*.


| Род / число | Именительный | Родительный |
| ----------- | ------------ | ----------- |
| м.р. ед.ч.  | ο            | **του**     |
| ж.р. ед.ч.  | η            | **της**     |
| ср.р. ед.ч. | το           | **του**     |
| м.р. мн.ч.  | οι           | **των**     |
| ж.р. мн.ч.  | οι           | **των**     |
| ср.р. мн.ч. | τα           | **των**     |


Во множественном числе артикль один для всех родов: **των**.

### Неопределённый (ένας / μία / ένα)

«Какой-то / один»: *книга одного друга*, *дом какой-то женщины*.  
Склоняется только в **единственном** числе.


| Род       | Именительный     | Родительный      | Пример                                      |
| --------- | ---------------- | ---------------- | ------------------------------------------- |
| м.р. ед.ч.  | **ένας**       | **ενός**         | το σπίτι ενός φίλου — дом одного друга      |
| ж.р. ед.ч.  | **μία** / **μια** | **μίας** / **μιας** | το βιβλίο μιας φίλης — книга одной подруги |
| ср.р. ед.ч. | **ένα**        | **ενός**         | το όνομα ενός παιδιού — имя какого-то ребёнка |


Мужской и средний в родительном совпадают: **ενός** (как **του** у определённого).  
У женского чаще разговорная форма **μιας**; **μίας** — более книжная.

**Множественного неопределённого артикля нет.**  
«Каких-то / некоторых» передают иначе: без артикля, через **κάποιοι / μερικοί** или через **από** + винительный  
(*το αυτοκίνητο κάποιων φίλων* — машина каких-то друзей).

## Существительные: как меняется окончание



### Мужской род


| Тип                        | Именительный    | Родительный      | Пример                       |
| -------------------------- | --------------- | ---------------- | ---------------------------- |
| **-ος**                    | ο άνθρωπ**ος**  | του ανθρώπ**ου** | του ανθρώπου — человека      |
| **-ας**                    | ο άνδρ**ας**    | του άνδρ**α**    | του άνδρα — мужчины          |
| **-ης**                    | ο μαθητ**ής**   | του μαθητ**ή**   | του μαθητή — ученика         |
| **-ης** (профессии и т.п.) | ο καθηγητ**ής** | του καθηγητ**ή** | του καθηγητή — преподавателя |


У **-ος** окончание → **-ου**.  
У **-ας / -ης** обычно отпадает **-ς** (остаётся основа).

### Женский род


| Тип            | Именительный | Родительный    | Пример             |
| -------------- | ------------ | -------------- | ------------------ |
| **-α**         | η μέρ**α**   | της μέρ**ας**  | της μέρας — дня    |
| **-η**         | η αγάπ**η**  | της αγάπ**ης** | της αγάπης — любви |
| **-ος** (ж.р.) | η οδ**ός**   | της οδ**ού**   | της οδού — улицы   |


У **-α / -η** добавляется **-ς**.  
У женского **-ος** — как у мужского: → **-ου**.

### Средний род


| Тип     | Именительный  | Родительный      | Пример                 |
| ------- | ------------- | ---------------- | ---------------------- |
| **-ο**  | το βιβλί**ο** | του βιβλί**ου**  | του βιβλίου — книги    |
| **-ι**  | το αγόρ**ι**  | του αγορι**ού**  | του αγοριού — мальчика |
| **-μα** | το όνο**μα**  | του ονό**ματος** | του ονόματος — имени   |


У **-ο** → **-ου**.  
У **-ι** → **-ιού** (часто с ударением на **-ού**).  
У **-μα** → **-ματος**.

## Множественное число

Артикль во множественном родительном один для всех родов: **των**.  
Ориентир по окончанию: почти всегда **-ων** (часто с ударением на **-ών**).

### Мужской род


| Тип                        | Именительный мн. | Родительный мн.    | Пример                          |
| -------------------------- | ---------------- | ------------------ | ------------------------------- |
| **-ος**                    | οι άνθρωπ**οι**  | των ανθρώπ**ων**   | των ανθρώπων — людей            |
| **-ας**                    | οι άνδρ**ες**    | των ανδρ**ών**     | των ανδρών — мужчин             |
| **-ης**                    | οι μαθητ**ές**   | των μαθητ**ών**    | των μαθητών — учеников          |
| **-ης** (профессии и т.п.) | οι καθηγητ**ές** | των καθηγητ**ών**  | των καθηγητών — преподавателей  |


У **-ος**: именительный мн. **-οι**, родительный мн. **-ων**.  
У **-ας / -ης**: именительный мн. **-ες**, родительный мн. **-ών**.  
Ударение в родительном мн. часто уходит на окончание (*των ανδρών*, *των μαθητών*).

### Женский род


| Тип            | Именительный мн. | Родительный мн.  | Пример                      |
| -------------- | ---------------- | ---------------- | --------------------------- |
| **-α**         | οι μέρ**ες**     | των ημερ**ών**   | των ημερών — дней           |
| **-η**         | οι τέχν**ες**    | των τεχν**ών**   | των τεχνών — искусств       |
| **-ος** (ж.р.) | οι οδ**οί**      | των οδ**ών**     | των οδών — улиц             |


У **-α / -η**: именительный мн. **-ες**, родительный мн. **-ων** / **-ών**.  
У женского **-ος**: именительный мн. **-οί**, родительный мн. **-ών** (как у мужского **-ος**, но ударение обычно на окончании).  
У части слов на **-α** в родительном мн. видна полная основа: *η μέρα → των **η**μερών* (встречается и *των μερών*).

### Средний род


| Тип     | Именительный мн.   | Родительный мн.      | Пример                    |
| ------- | ------------------ | -------------------- | ------------------------- |
| **-ο**  | τα βιβλί**α**      | των βιβλί**ων**      | των βιβλίων — книг        |
| **-ι**  | τα αγόρ**ια**      | των αγορι**ών**      | των αγοριών — мальчиков   |
| **-μα** | τα ονό**ματα**     | των ονο**μάτων**     | των ονομάτων — имён       |


У **-ο** → именительный мн. **-α**, родительный мн. **-ων**.  
У **-ι** → именительный мн. **-ια**, родительный мн. **-ιών** (ударение на **-ών**).  
У **-μα** → именительный мн. **-ματα**, родительный мн. **-μάτων**.

## Личные местоимения в родительном

Сопоставление то же, что в русском: **я → мой**, **εγώ → μου**.

**μου** не меняется по роду вещи: *моя книга* и *мой дом* — оба **μου**.  
Обычно стоит **после** существительного: **το βιβλίο μου** — моя книга.


| Русский     | Ελληνικά              | Пример            |
| ----------- | --------------------- | ----------------- |
| я — мой     | **εγώ** — **μου**     | το βιβλίο μου     |
| ты — твой   | **εσύ** — **σου**     | το όνομά σου      |
| он — его    | **αυτός** — **του**   | το σπίτι του      |
| она — её    | **αυτή** — **της**    | το αυτοκίνητό της |
| оно — его   | **αυτό** — **του**    | το όνομά του      |
| мы — наш    | **εμείς** — **μας**   | η δουλειά μας     |
| вы — ваш    | **εσείς** — **σας**   | το όνομά σας      |
| они — их    | **αυτοί** — **τους**  | τα παιδιά τους    |

| моя работа       | η δουλειά μου            |
| их дети          | τα παιδιά τους           |

## На что обратить внимание

1. **Артикль обязателен** почти всегда: известный обладатель — *του φίλου*; неизвестный / «один» — *ενός φίλου*. Без артикля (*φίλου*) обычно нельзя.
2. Ударение может сдвигаться (*το αγόρι → του αγορ**ιού***).
3. Имена тоже склоняются: *η Μαρία → της Μαρίας*, *ο Γιάννης → του Γιάννη*.
4. Если форма родительного пока сложная — можно сказать через **από** + винительный, но для чтения и «правильной» речи учи родительный отдельно.
