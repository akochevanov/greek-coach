# Слова места

Слова: εδώ, εκεί, πάνω, κάτω, μέσα, έξω, κοντά, μακριά, πίσω, μπροστά, παντού, πουθενά.

В транскрипции **заглавная гласная** = ударная.

| Русский | Ελληνικά |
| ------- | -------- |
| Книга здесь. | Το βιβλίο είναι εδώ. |
| Мы работаем здесь. | Δουλεύουμε εδώ. |
| Дети там. | Τα παιδιά είναι εκεί. |
| Я иду туда. | Πάω εκεί. |
| Вода на столе. | Το νερό είναι πάνω στο τραπέζι. |
| Я иду наверх. | Πάω πάνω. |
| Деньги внизу. | Τα λεφτά είναι κάτω. |
| Я спускаюсь вниз. | Κατεβαίνω κάτω. |
| Я вхожу внутрь. | Μπαίνω μέσα. |
| Я внутри дома. | Είμαι μέσα στο σπίτι. |
| Я выхожу наружу. | Βγαίνω έξω. |
| Дети снаружи. | Τα παιδιά είναι έξω. |
| Магазин рядом. | Το μαγαζί είναι κοντά. |
| Я живу рядом с работой. | Μένω κοντά στη δουλειά. |
| Я живу далеко. | Μένω μακριά. |
| Дом далеко отсюда. | Το σπίτι είναι μακριά από εδώ. |
| Я иду назад. | Πάω πίσω. |
| Дети позади. | Τα παιδιά είναι πίσω. |
| Стул впереди. | Η καρέκλα είναι μπροστά. |
| Я стою перед дверью. | Στέκομαι μπροστά από την πόρτα. |
| Дети везде. | Τα παιδιά είναι παντού. |
| Я хожу везде. | Πάω παντού. |
| Я никуда не иду. | Δεν πάω πουθενά. |
| Денег нигде нет. | Τα λεφτά δεν είναι πουθενά. |
