# Связки — союзы

Слова: γιατί, επειδή, αλλά, όμως, ή, και, ώστε, αν, ότι, για να, ενώ, μόλις, για παράδειγμα.

В транскрипции **заглавная гласная** = ударная.

**γιατί** и **επειδή** — «потому что». **γιατί** также значит «почему».

| Русский | Ελληνικά |
| ------- | -------- |
| Я не пришел, потому что работал. | Δεν ήρθα γιατί δούλευα. |
| Я ухожу, потому что поздно. | Φεύγω γιατί είναι αργά. |
| Так как идет дождь, мы останемся дома. | Επειδή βρέχει, θα μείνουμε σπίτι. |
| Так как у меня нет времени, я не прихожу. | Επειδή δεν έχω χρόνο, δεν έρχομαι. |
| Я хочу пойти, но не могу. | Θέλω να πάω, αλλά δεν μπορώ. |
| Я хочу кофе, но у меня нет сахара. | Θέλω καφέ, αλλά δεν έχω ζάχαρη. |
| Было сложно, однако мы справились. | Ήταν δύσκολο, όμως τα καταφέραμε. |
| У меня нет времени, однако я прихожу. | Δεν έχω χρόνο, όμως έρχομαι. |
| Ты хочешь кофе или чай? | Θέλεις καφέ ή τσάι; |
| Мы едим сейчас или потом? | Τρώμε τώρα ή μετά; |
| Я купил хлеб и молоко. | Αγόρασα ψωμί και γάλα. |
| Я пью кофе и читаю. | Πίνω καφέ και διαβάζω. |
| Говори четко, чтобы тебя слышали. | Μίλα καθαρά ώστε να σε ακούνε. |
| Говори медленно, чтобы я тебя понимал. | Μίλα αργά ώστε να σε καταλαβαίνω. |
| Если хочешь, пойдем с нами. | Αν θέλεις, έλα μαζί μας. |
| Если у тебя есть время, приходи. | Αν έχεις χρόνο, έλα. |
| Я знаю, что ты прав. | Ξέρω ότι έχεις δίκιο. |
| Я знаю, что ты сегодня работаешь. | Ξέρω ότι δουλεύεις σήμερα. |
| Я пришел, чтобы поговорить с тобой. | Ήρθα για να σου μιλήσω. |
| Я иду в магазин, чтобы купить хлеб. | Πάω στο μαγαζί για να αγοράσω ψωμί. |
| Я читал, в то время как он готовил. | Διάβαζα ενώ εκείνος μαγείρευε. |
| Я работаю, в то время как ты спишь. | Εγώ δουλεύω ενώ εσύ κοιμάσαι. |
| Позвони мне, как только приедешь. | Πάρε με τηλέφωνο μόλις φτάσεις. |
| Я уйду, как только закончится урок. | Θα φύγω μόλις τελειώσει το μάθημα. |
| Например, я пью кофе утром. | Για παράδειγμα, πίνω καφέ το πρωί. |
| Например, я живу здесь. | Για παράδειγμα, μένω εδώ. |
