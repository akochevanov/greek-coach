# Связки — неопределённости

Слова: τίποτα, κάτι, κανένας, όλα, όλοι, καθένας, κάποιος, κάθε.

В транскрипции **заглавная гласная** = ударная.

**όλα** — «всё» (вещи). **όλοι** — «все» (люди).  
**κάθε** стоит перед существительным (*каждый день*). **καθένας** — само по себе (*каждый*).

| Русский | Ελληνικά |
| ------- | -------- |
| Я ничего не хочу. | Δεν θέλω τίποτα. |
| Я ничего не вижу. | Δεν βλέπω τίποτα. |
| Я хочу что-то. | Θέλω κάτι. |
| Я вижу что-то. | Βλέπω κάτι. |
| Никого здесь нет. | Κανένας δεν είναι εδώ. |
| Никто здесь не работает. | Κανένας δεν δουλεύει εδώ. |
| Всё хорошо. | Όλα είναι καλά. |
| Я покупаю всё. | Αγοράζω όλα. |
| Все здесь. | Όλοι είναι εδώ. |
| Все идут на работу. | Όλοι πάνε στη δουλειά. |
| Каждый хочет кофе. | Καθένας θέλει καφέ. |
| У каждого есть книга. | Καθένας έχει βιβλίο. |
| Кто-то здесь. | Κάποιος είναι εδώ. |
| Кто-то звонит. | Κάποιος παίρνει τηλέφωνο. |
| Каждое утро я пью кофе. | Κάθε πρωί πίνω καφέ. |
| Каждый день я читаю. | Κάθε μέρα διαβάζω. |
