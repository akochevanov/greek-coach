# Вспомогательные слова

Слова сгруппированы по грамматической роли — так их проще вспоминать в разговоре.

## Наречия времени

| Ελληνικά                    | Русский                  |
| ---------------------------- | ------------------------- |
| όταν (отан)                  | когда (союз)              |
| πότε (потэ)                  | когда (вопрос)            |
| ποτέ (потэ)                  | никогда / когда-либо      |
| πάντα (панда)                | всегда                    |
| μετά (мета)                  | после, потом              |
| τότε (тотэ)                  | тогда                     |
| μερικές φορές (мерикэс форэс) | иногда                    |
| πάλι (пали)                  | снова, опять              |
| ήδη (иди)                    | уже                       |
| ακόμα (акома)                | ещё, всё ещё              |
| σήμερα (симера)              | сегодня                   |
| χθες (хтэс)                  | вчера                     |
| αύριο (аврио)                | завтра                    |
| τώρα (тора)                  | сейчас                    |
| συχνά (сихна)                | часто                     |
| σπάνια (спания)               | редко                     |
| πρώτα (прота)                | сначала, сперва           |
| αμέσως (амэсос)              | немедленно, сразу         |

## Союзы / связки

| Ελληνικά         | Русский                          |
| ----------------- | ---------------------------------- |
| γιατί (яти)       | потому что                        |
| επειδή (эпиди)    | так как, потому что               |
| αλλά (ала)        | но                                 |
| όμως (омос)       | однако, тем не менее              |
| ή (и)             | или                                |
| και (кэ)          | и                                  |
| αν (ан)           | если                               |
| ότι (оти)         | что (вводит придаточное)          |
| για να (я на)     | для того чтобы                    |
| ενώ (эно)         | в то время как, хотя              |
| μόλις (молис)     | как только                        |
| αφού (афу)        | после того как; так как           |

## Вопросительные слова

| Ελληνικά                                | Русский          |
| ----------------------------------------- | ----------------- |
| γιατί (яти)                               | зачем / почему    |
| πότε (потэ)                               | когда             |
| πού (пу)                                  | где / куда        |
| πώς (пос)                                 | как               |
| τι (ти)                                   | что               |
| ποιος / ποια / ποιο (пьос / пья / пьо)    | кто / какой       |
| πόσο (посо)                               | сколько           |
| πόσος / πόση / πόσο (посос / поси / посо) | сколько (согласуется с существительным) |

## Местоимения-неопределённые

| Ελληνικά                                   | Русский                    |
| --------------------------------------------- | ---------------------------- |
| τίποτα (типота)                               | ничего / что-нибудь         |
| κάτι (кати)                                   | что-то, кое-что              |
| κανένας / καμία / κανένα (канэнас / камия / канэна) | никто, ни один / кто-нибудь |
| κάποιος / κάποια / κάποιο (капьос / капья / капьо) | кто-то, некто               |
| όλα (ола)                                     | всё                          |
| όλοι (оли)                                    | все (люди)                  |
| κάθε (кафэ)                                   | каждый                       |

| Ελληνικά             | Русский              |
| --------------------- | ---------------------- |

| με (мэ)               | с                       |
| για (я)                | для / за / про         |
| χωρίς (хорис)         | без                     |
| πριν (прин)           | до, перед               |
| μετά από (мета апо)   | после (чего-то)         |
| μέχρι (мэхри)         | до                      |
| πάνω σε (пано сэ)     | на (поверхности)        |
| κάτω από (като апо)   | под                     |
